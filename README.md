# Deexcellentcrib Website — Original Design, Responsive Navigation Update

This version preserves the original black, gold and light-neutral visual identity, including Playfair Display headings and Inter body text, while improving navigation clarity, mobile responsiveness and accessibility.

## Publish with GitHub Pages

1. Extract this ZIP file.
2. Open `Deexcellentcrib-Website-main`.
3. Upload the **contents** of that folder to the root of the `Deexcellentcrib-Website` GitHub repository (keep `index.html` at the repository root).
4. Commit the changes and wait for GitHub Pages to deploy.

## Changes in this update

- Replaced the crowded navigation with clear links to real page sections.
- Added an accessible mobile slide-out menu with open/close state, Escape-key support, outside-click closing, body-scroll locking and a consultation CTA.
- Added active-section navigation state and fixed-header-aware smooth scrolling.
- Improved navigation spacing and contrast while preserving the original palette and fonts.
- Added responsive refinements for tablets, small phones and narrow screens.
- Added keyboard focus states and reduced-motion handling.
- Checked all in-page links for valid section targets and validated JavaScript syntax.

## Before going live

Confirm the business WhatsApp number and contact email. Replace inspiration images with authorised photos of completed work when available. The contact form opens WhatsApp with a prefilled enquiry; it does not store form submissions on a server.
